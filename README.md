# Command Line Interface Club Member Directory

This is a simple python program for managing club members.

## Features

- Add a member
- Remove a member
- List all members
- Search members by domain
- Exit the program

## Information Stored

For each member, the program stores:

- Member Name
- Domain

## How to Run

1. Open the `clubmember.py` file in any python IDE or VS code
3. Run the program.
4. Select an option from the menu.

## Menu

1. Add Member
2. Remove Member
3. List all members
4. Search by Domain
5. Exit
